# セキュリティ / Security

記録の改ざん検知・鍵の扱い・送信内容に関わる脆弱性を見つけたときは、公開の Issue ではなく次に連絡してください。

- メール: security@nenrinapp.com(届かない場合は support@nenrinapp.com)
- 内容: 再現手順、影響(何が偽造・改ざんできるか)、可能なら修正案

受け取ってから 3 営業日以内に返信します。修正が配布アプリに乗るまで公開を待っていただけると助かります(報告者名は本人の希望に従って記載します)。

**範囲**: このパッケージ(記録・チェーン・鍵・検証・アンカー送信)。サーバー側(nenrinapp.com)の脆弱性も同じ窓口で受け付けます。

If you find a vulnerability in tamper detection, key handling or what this code sends, please email security@nenrinapp.com instead of opening a public issue. We reply within 3 business days and appreciate coordinated disclosure.
